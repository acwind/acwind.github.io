## 1. ClipWise —— 智能剪贴板内容清洗工具

**核心功能**：自动检测并清洗剪贴板内容的格式杂质（ANSI 转义码、Shell 提示符、行号、富文本格式），只保留纯文本，常驻 macOS 菜单栏。

**创意来源**：HN Show 上的 [cpcp 项目](https://github.com/Vansh-j/CopyCopy) 展示了终端复制时自动去除 ANSI 码和换行的思路。但它的功能局限在终端管道场景。实际痛点是：开发者从终端、IDE、代码审查页面复制代码时，总是带出 $ 提示符、行号、Git diff 标记、ANSI 颜色码等垃圾信息。没有一个通用工具能自动识别上下文并做智能清洗。

**技术路径**：Swift/SwiftUI（macOS 原生菜单栏应用）+ NSPasteboard 监听。核心是维护一组"脏模式"正则规则（ANSI 序列、行号前缀、diff 标记等），复制事件触发时自动匹配并清洗。可扩展插件机制来适配不同来源。

**差异化优势**：相比手动运行 pbcopy -p 或安装独立 CLI 工具，ClipWise 在后台无声运行，无需用户主动操作。它比 macOS 内置的"粘贴并匹配样式"更智能——不仅能去格式，还能识别并去除特定上下文垃圾。极简 UI：菜单栏图标 + 最近清理历史。

## 2. 火眼 —— YouTube 视频内容质量检测器

**核心功能**：浏览器扩展，在看 YouTube 之前就告诉你这个视频是不是"标题党"、有多少真实内容、核心信息时间戳在哪。

**创意来源**：Reddit r/SomebodyMakeThis 上的 [用户痛点讨论](https://www.reddit.com/r/SomebodyMakeThis/comments/1ujkd88/would_you_install_a_youtube_bullshit_detector/)——花了 20-40 分钟看一个承诺"exact strategy"的视频，结果 18 分钟里有 15 分钟是漏斗推广和废话。用户希望有个工具能在标题下方标注"该视频内容密度：低/中/高"并直接给出核心内容锚点。

**技术路径**：Chrome/Firefox 浏览器扩展（Manifest V3）+ 后端服务节点（可 Node.js/Python）。抓取视频字幕/文字稿后，用轻量 NLP 模型（如本地 Transformer 或调用便宜 LLM API）分析：内容/推广比例、信息密度曲线、关键观点提取。缓存分析结果减少重复计算。

**差异化优势**：现有解决方案只有用户手动翻评论区找"timestamp"——不系统、不准确。火眼将这件事自动化，给每个视频打一个"实用分"。核心差异在于不依赖用户社区贡献，而是通过视频文字稿做实时分析。未来可扩展：标记"纯推广"视频、推荐同类高质量内容。

## 3. SayScript —— 自然语言脚本执行器

**核心功能**：桌面客户端（CLI + GUI），你用人话描述任务（"把 Downloads 里所有 .jpg 文件按月份归档到 Photos 目录"），它自动理解、生成并执行对应的 Shell/Python 脚本，无需写一行代码。

**创意来源**：V2EX 用户分享的 [yeero do](https://www.v2ex.com/t/1224607) 项目展示了用自然语言描述任务、自动匹配或生成 Python 脚本执行的思路。这个痛点在开发者社区非常普遍：每天都有一堆小型文件操作任务（批量重命名、格式转换、数据提取），每次都去查 Stack Overflow 或手写脚本太浪费时间。

**技术路径**：Electron 或 Tauri 桌面应用 + 本地 LLM（如 llama.cpp 运行 Qwen2.5 7B）做 NL→Shell 翻译。架构为"沙箱预览 + 一次确认"模式：AI 生成脚本后在界面展示具体操作列表（"将要执行以下操作：重命名 12 个文件、创建 3 个目录……"），用户确认后才执行，避免安全风险。可加 undo 功能。

**差异化优势**：与 yeero do 不同，SayScript 面向更广泛的非技术用户（设计师、运营），提供 GUI 确认界面而非纯 CLI。核心差异：安全优先（预览 + 确认 + undo），离线可用（本地 LLM），支持自然语言纠错（"不，按修改日期分，不是创建日期"）。

## 4. MoonGlance —— 极简月相观测工具

**核心功能**：精美网页应用，选择任意日期、时间、GPS 位置，在 3D 地球仪上点击一点，即显示当时当地真实可见的月亮——月相、方位、高度、升起落下时间。

**创意来源**：V2EX 用户分享的[那天的月亮](https://www.v2ex.com/t/1224827)项目，在 3D 线框地球仪上选地点和时间查看月相。这是一个典型的"功能单一但体验极致"的小工具——不试图做大而全的天文软件，就专注做"月亮这一刻长什么样"这一件事。

**技术路径**：纯前端（Next.js + Three.js 或 React + Cesium）。天文计算使用 well-known 算法（如 NOAA 的天文算法）在浏览器端实时计算，无需后端。UI 设计极致简约：一个时间选择器 + 一个地球仪 + 月相显示，没有任何多余的控件。

**差异化优势**：现有天文 App（Stellarium、Star Walk）功能庞大且复杂，启动慢、广告多。MoonGlance 只做一件事：输入时间和地点，看月亮。极致的加载速度（纯前端计算）、极简的 UI 设计、可分享的永久链接（方便好友间分享"今天月亮长这样"）。适合作为社交媒体分享卡片的嵌入工具。
