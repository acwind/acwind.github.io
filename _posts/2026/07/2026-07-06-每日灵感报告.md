## 1. HushMic — 麦克风激活时自动暂停播放

**核心功能**：系统检测到麦克风被唤醒（语音输入/语音转文字）时，自动暂停当前正在播放的音频/视频，麦克风停止使用后自动恢复播放。

**创意来源**：V2EX 用户分享了一款已实现的 macOS 小工具 HushMic（https://github.com/location-txl/HushMic），创意本身非常简洁优雅——使用语音输入法进行语音转文字时，播客或音乐会干扰识别效果，而系统缺少自动暂停机制。同类需求在语音输入场景越来越普及的今天会持续增长。

**技术路径**：macOS 原生（Swift/SwiftUI）调用 CoreAudio 监听音频输入状态变更 + 媒体播放控制（AppleScript 或 MediaPlayer 框架）。Windows 版可用 C#/WinRT 实现。

**差异化优势**：市面上没有单独解决"语音输入时自动静音"这一场景的工具。现有方案需要用户手动调音量，体验割裂。这个工具只做一件事且做得天衣无缝——适合作为独立开发者的首款产品，1 周完成 MVP。

## 2. 家庭到期管家 — 重要证件/合约到期日追踪

**核心功能**：集中管理家庭的护照、驾照、保修期、车检、保险续约、FSA 余额清零等一切具有"到期日"的重要事项，到期前自动发送提醒。

**创意来源**：Reddit r/SomebodyMakeThis 用户调研家庭痛点时发现——护照过期毁了旅行、保修过期多花 300 刀修东西、FSA 年底清零忘用、车检逾期被罚款。这些"昂贵的小事"没有好用的追踪工具。现有方案要么是通用日历需手动操心，要么是大而全的家庭管理软件过于臃肿。

**技术路径**：Web 端（React/Next.js + SQLite）或移动端（Flutter + 本地通知）。核心逻辑可以简单到只有 CRUD + 日历计算 + 推送通知。数据完全本地存储，无需后端。

**差异化优势**：极度聚焦——不做家庭记账、不做任务分配、不做购物清单，只做"到期提醒"这一件事。比日历更智能（知道驾照是每 5 年/10 年到期），比 Notion 模板更零门槛。独立开发者 1-2 周可完成 MVP。

## 3. YouTube AudioScrub — 音频搓碟式进度条预览

**核心功能**：在 YouTube 上拖动播放进度条时，像 DJ 搓碟一样实时播放当前位置的音频，让用户可以"听"着找想要的片段，而非依赖模糊的视频帧预览。

**创意来源**：Reddit r/SomebodyMakeThis 用户提出——看长视频/教程/播客时经常需要快速翻到特定位置，但 YouTube 默认只有帧预览且不带音频，效率极低。如果有类似 DJ 搓碟的音频反馈，定位会准确得多。

**技术路径**：浏览器扩展（Manifest V3，JavaScript）。核心是拦截 YouTube 播放器的 timeupdate 事件，在 seek 过程中保持音频输出。可参考音频编辑器的 scrubbing 实现。

**差异化优势**：解决了一个非常具体但尚未被满足的交互痛点。YouTube 用户基数庞大，即使只有 0.1% 的用户有这种需求，也是百万级市场。扩展开发成本极低（纯前端，无需服务器），适合作为第一个练手项目。

## 4. Flit — 轻量化原生感修图工具

**核心功能**：一款安静、轻量的本地照片编辑器，专注于胶片风格色彩分级、滤镜、LUT、水印和边框。避免复杂工作流，将核心编辑工具整合到简洁专注的界面中。

**创意来源**：V2EX 用户分享的 Flit 修图 App，切入点是"轻度修图用户的共同烦恼"——现有 App 要么过于臃肿商业化严重，要么缺乏 iPad 适配。很多人只需要简单调色 + 胶片风格 + 加边框/水印，却被逼着用 Lightroom 或美图秀秀。

**技术路径**：原生开发（iOS/macOS 用 Swift + Metal 滤镜，或 Flutter + Skia）。核心模块：基础调色工具、LUT 映射引擎、滤镜预设系统。关键是从一开始就坚持"功能克制"的设计哲学。

**差异化优势**：在"极致简单"这个维度上做到极致。对比 VSCO（已商业化臃肿）、Lightroom（专业但复杂），Flit 的定位是"纯粹为喜欢胶片感+简单调色的人准备的工具"。适合有设计感的独立开发者，1-2 周可完成首个可用版本。

## 5. FlowPick — 页面媒体一键嗅探器

**核心功能**：一个浏览器扩展，无需打开 F12 开发者工具，即可一键嗅探当前网页上所有视频、音频和图片资源，并批量下载。

**创意来源**：Appinn 发现频道本周热门排行榜第一名。很多网站不提供直接的下载按钮，而用浏览器开发者工具查找资源对普通用户来说门槛太高。FlowPick 将这一流程简化为"点一下扩展图标→看到所有媒体资源→点击下载"。

**技术路径**：浏览器扩展（JavaScript，Manifest V3）。核心通过 Resource Timing API 和 DOM 解析捕获媒体 URL。开源免费。

**差异化优势**：解决的是"小需求但高频"的场景。FlowPick 的开源属性是最大护城河——用户可以放心使用，不用担心隐私问题。这个模式本身也值得借鉴：找到开发者用 F12 才能做的事，将其包装成普通用户也能一键使用的产品。
