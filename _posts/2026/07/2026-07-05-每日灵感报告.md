## 1. FocusMic — 锁定 macOS 麦克风输入设备

**核心功能**：锁定 macOS 的音频输入设备，防止 AirPods 等蓝牙设备自动切换导致麦克风错乱。

**创意来源**：V2EX 用户分享了近期的 macOS 小工具，解决的是日常开发的真实痛点——戴着有线麦克风时，AirPods 一连接系统就自动切换音频输入，导致会议或录音中断。这类需求在开发者社区中频繁出现。

**技术路径**：Swift + CoreAudio API（AudioObjectGetPropertyData / AudioObjectSetPropertyData），菜单栏图标式应用，用 AppleScript 配合 CoreAudio 监听设备状态变化。

**差异化优势**：现有系统偏好设置无法锁定音频输入设备，每次都要手动切换。只做一件事——记住你选好的麦克风，不让任何设备把它抢走。极简、专注、1 天可出 MVP。

## 2. 家庭到期管家（Life Shelf Life）

**核心功能**：统一管理家庭中所有"会过期"的重要事项（护照、保修、FSA 余额、车辆注册、保险续期），在到期前 30 天/7 天/1 天发送邮件提醒。

**创意来源**：Reddit r/SomebodyMakeThis 上一位开发者正在构建家庭到期微 SaaS，引发大量共鸣。用户痛点明确：护照过期毁掉旅行、保修过期多花 300 美元修东西、FSA 余额年底清零没人提醒——现有方案各管一摊（仅管保修、仅管食物、仅管证件），没有统一面板。

**技术路径**：Next.js + TailwindCSS + Supabase（认证 + 数据库 + 定时任务）。邮件提醒用 Resend/SendGrid。先用 Web 版验证需求，后续加移动端。定价 $5/月（支持 5 个家庭成员），完全可独立开发。

**差异化优势**：不做"又一个提醒 App"，而是"你家所有会过期东西的唯一控制面板"。按到期时间排序、一个界面看完全局、家庭成员共享。

## 3. YouTube 内容脱水器（Bullshit Detector）

**核心功能**：YouTube 浏览器扩展，自动检测视频是否为标题党/营销漏斗，给出真正有信息量的时间戳，让你直接跳到干货所在位置。

**创意来源**：Reddit 一位用户抱怨 YouTube 上大量教程视频"把 3 分钟干货拉成 18 分钟"，引发 100+ 条讨论，几乎人人都说遇到了同样的问题。有人提到希望有个浏览器扩展能"检测点击诱饵"。

**技术路径**：Chrome Extension Manifest V3 框架，前端用 React/Popup 界面，核心逻辑通过 YouTube Transcript API 获取字幕，调用 OpenAI/Claude API 分析内容密度，识别营销信号（如"book a call""schedule a strategy session"等关键词），标注高价值片段。后端轻量（Cloudflare Workers），API 用 BYOK（自带密钥）模式避免服务器成本。

**差异化优势**：不是简单的倍速播放或跳过片头片尾——而是真正的**内容密度分析**。用 AI 识别哪些段落有实际交付价值（"here's the code""the key insight is"），哪些是漏斗铺垫。让用户在看之前就知道："这个视频真正有用的 3 分钟在 12:30-15:45"。

## 4. Discord 时间戳生成器

**核心功能**：一个极简网页工具，选择时间和时区，一键生成 Discord `<t:unix:F>` 格式时间戳，直接复制粘贴即可在社区中使用。

**创意来源**：V2EX 用户做了 Disclock.io 并分享，发现现有工具要么广告多、要么操作别扭。Discord 社区中跨国约时间是非常高频的场景，但大多数人记不住 Unix 时间戳的格式，每次都要靠第三方机器人或手动计算。

**技术路径**：纯前端 PWA（Progressive Web App），React/Vue + dayjs/luxon 处理时区转换。核心功能 0 后端成本，可托管于 Vercel/Cloudflare Pages。可扩展功能：暗色模式、时区常用城市收藏、Discord Embed 预览、历史生成记录（localStorage）。

**差异化优势**：极致简洁——打开即用，没有广告，没有注册，没有多余功能。支持并收藏常用时区（如 UTC+8、UTC-5、UTC+1），一次设置重复使用。可嵌入其他网站作为 widget。

## 5. Suno 音质修复工具（Desunofier）

**核心功能**：在线工具，通过音频处理算法减少 Suno AI 生成歌曲中标志性的"金属颤音/齿音"（shimmer），提升听感质量。

**创意来源**：HN Show 上一位有音频混音背景的开发者展示了他的作品。Suno 生成音乐中的人声和高频乐器带有明显的 shimmer 伪影，已经成为 AI 音乐的"水印"，用户一听就能识别。他用 DAW 中的混音技巧将其转化为代码，做了个网页版工具。

**技术路径**：前端 Web Audio API + 频谱处理（多频段压缩 + de-esser 算法），纯浏览器端运行，无需上传到服务器（保护用户隐私）。核心是检测 4-8kHz 频段的谐振峰，用动态均衡器压制。熟悉音频 DSP 的话，核心逻辑可在 200 行代码内完成。

**差异化优势**：填补了 AI 后期处理的空白——目前 Suno、Udio 等 AI 音乐平台没有内置音频后期能力，用户只能导出到 DAW 手动处理。这个工具让不会混音的用户也能一键改善音质。超细分市场（AI 音乐创作者），但用户粘性极高。
